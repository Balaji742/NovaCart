# NovaCart 🛒

A modern React-based ecommerce application built for portfolio and learning purposes. NovaCart demonstrates authentication, state management, cart persistence, order management, responsive design, and Firebase integration.

## 🚀 Live Demo

https://nova-cart-zeta-three.vercel.app

## 📌 Features

### User Authentication
- Register account
- Login & Logout
- Firebase Authentication
- Session persistence

### Product Catalog
- Product listing
- Category filtering
- Search functionality
- Pagination
- Responsive product cards

### Shopping Cart
- Add to cart
- Remove from cart
- Increase / decrease quantity
- Cart sidebar
- Cart persistence using Local Storage

### Orders
- Place orders
- View order history
- Order details popup
- Cancel orders
- Firestore database integration

### Responsive Design
- Mobile friendly
- Tablet friendly
- Desktop friendly
- Bootstrap 5 UI

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Balaji742/NovaCart.git
```

Navigate to project folder:

```bash
cd NovaCart
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
